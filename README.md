# FlutterFlow To-Do

A simple To-Do application built with FlutterFlow using a custom Dart widget.

## Features

- Add new tasks
- Edit existing tasks
- Mark tasks as complete or active
- Delete tasks
- Filter by All, Active, and Done
- Task completion progress
- Device-local persistence using `shared_preferences`
- Responsive Material 3 interface

## Live Demo

https://todolist-sivn1m.flutterflow.app

## Project structure

- `flutterflow/todo_list_widget.dart` — FlutterFlow custom widget source
- `docs/START_HERE.md` — setup and usage instructions

## Important

This repository contains the custom-widget source used for the project, not a complete FlutterFlow project export or APK.

## Dependency

The custom widget uses `shared_preferences` (`^2.3.0` or a compatible newer 2.x version).

See `docs/START_HERE.md` for FlutterFlow installation instructions.
